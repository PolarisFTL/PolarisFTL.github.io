# Background image

The current user-supplied background is stored in this directory as `black-clover-bg.jpg`. Replace it with another legally obtained image using the same filename when needed.

The Clover theme automatically layers a dark, desaturated overlay above it. If the file is absent, the site uses its built-in charcoal and forest-green gradient without any visible breakage. Keep the image around 500 KB–1 MB for a fast homepage.
